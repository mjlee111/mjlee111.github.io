mjlee. editor 폴더를 열어 시작하세요

사이트 편집기

  1. 사이트 폴더 열기로 index.html이 있는 폴더를 선택합니다 (Chrome / Edge).
  2. 왼쪽에서 내용을 고치면 오른쪽 미리보기에 바로 반영됩니다.
  3. 저장하면 바뀐 파일만 덮어쓰고, 덮어쓰기 전 내용은 _backup/<시각>/에 보관합니다.
  4. tbd 체크는 미완성 표시(노란 강조)입니다. 내용을 채웠으면 해제하세요.

이 브라우저는 폴더 저장을 지원하지 않습니다. index.html, script.js, style.css를 함께 선택해 열면, 저장할 때 수정된 파일이 다운로드됩니다. 이미지 업로드는 사용할 수 없습니다.
