# mjlee111.github.io

Personal profile site. Static HTML/CSS/JS, no build step.

## Files
- `index.html` — page content (About, Experience, Activities)
- `script.js` — `PROJECTS` array that renders the Projects section
- `style.css` — styles (light/dark)
- `images/` — `profile.jpg` and project images

## Filling in
Every placeholder has `class="tbd"` (shown highlighted). Replace the text and remove the class.

## Deploy
1. Create a public repo named `mjlee111.github.io`.
2. Push these files to the `main` branch root.
3. Settings → Pages → Source: Deploy from branch, `main` / `(root)`.
4. Site is served at https://mjlee111.github.io
